# Requilibrium – Sitio web oficial

Sitio web corporativo de **Requilibrium**, grupo especializado en el diseño de sistemas regenerativos que transforman el agua residual en agua limpia, energía renovable y composta.

🌐 **Sitio en producción:** [https://www.requilibrium.com](https://www.requilibrium.com)
🇲🇽 **Versión en español:** [https://requilibrium.com/es/](https://requilibrium.com/es/)

---

## 📖 Acerca del proyecto

Requilibrium diseña e integra proyectos hídricos completos y adaptados a cada sitio: agua potable, tratamiento de aguas residuales, reúso, almacenamiento, distribución e infraestructura integrada. Su método patentado combina procesos naturales con tecnologías seleccionadas para reducir costos de operación, generar energía renovable y fortalecer la autonomía local.

Este sitio presenta la visión y el método de la empresa, sus servicios, productos, proyectos destacados, conferencias, grupo y aliados, además de un formulario de contacto para nuevos proyectos.

## 🚀 Instalación y uso local

> Ajusta esta sección según el contenido real del repositorio (tema, plugins o sitio completo).

1. Clona el repositorio:
   ```bash
   git clone https://github.com/<usuario>/<repositorio>.git
   ```
2. Instala WordPress en tu entorno local (XAMPP, Local, Docker, etc.).
3. Copia los archivos del repositorio en `wp-content/` según corresponda (tema, plugins, uploads).
4. Importa la base de datos (si aplica) y actualiza las URLs del sitio.
5. Configura `wp-config.php` con tus credenciales locales.
6. Activa el tema y los plugins necesarios, incluido Elementor.

## 🔐 Seguridad

No subas al repositorio archivos con información sensible, por ejemplo:

- `wp-config.php` con credenciales reales
- Respaldos de base de datos
- Claves de API o tokens
- Archivos `.env`

Agrega estos archivos a tu `.gitignore`.
